План продукта · 2026-06-18

Transcriber → продукт

Переиспользуемое нативное ядро + macOS-приложение в строке меню. Тёмный интерфейс, локальная транскрипция двух дорожек, модели whisper и parakeet.
Rust core · UniFFI sherpa-onnx SwiftUI · NSStatusItem macOS 14+ · DMG + Sparkle iOS / Android — потом
