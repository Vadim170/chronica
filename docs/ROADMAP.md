# Chronica — roadmap

Что планируется после 0.1.0. Без дат: проект делается в свободное время, порядок
может меняться. Предложения и голоса — в issues.

**Ближайшее**

- **Homebrew cask** — установка одной командой вместо ручного скачивания DMG.
- **Скриншоты и короткое демо** в README.

**Дальше**

- **Sparkle** — обновление приложения изнутри вместо ручного похода в Releases.
- **Экспорт «дел» через API и CLI.** Сейчас экранные активности знает только
  приложение, поэтому `GET /api/v1/export` и `chronica export` отдают
  `activities` пустым массивом. Нужно поднять журнал экрана в ядро.
- **MCP-сервер поверх локального API** — чтобы языковая модель могла спросить
  «что я делал во вторник» без самописных обвязок.
- **Срок хранения транскрипции в интерфейсе.** У журнала экрана он уже
  настраивается, а транскрипция автоматически не чистится вовсе — только вручную
  через `chronica db retention`.

**Когда-нибудь**

- **Android** — клиент есть и работает на том же ядре, но публичного релиза нет:
  нужен стабильный фоновый сервис записи и проверка реального ASR на устройстве.
- **iOS** на том же ядре.
- **Переименование технических идентификаторов** (bundle id, крейт, каталог
  данных) вместе с миграцией разрешений и данных — см. «Про имя» в README.
